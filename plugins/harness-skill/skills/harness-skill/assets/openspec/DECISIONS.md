# Decisiones

Decisiones vigentes que afectan el rumbo del proyecto. Las decisiones
arquitectónicas con contexto completo van como ADRs en `adr/`.

| Decisión | Detalle |
|---|---|
| _Ejemplo_ | Usar el flujo `feature → develop → main` con push a `main` bloqueado. |

> Cuando una decisión tenga peso arquitectónico, creá un ADR (`adr/000N-titulo.md`)
> usando `adr/0000-template.md` y enlazalo aquí.
